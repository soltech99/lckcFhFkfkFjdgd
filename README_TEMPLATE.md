# Workflow Automation Application

Internal productivity tool for workflow automation using Google Workspace APIs.

## Overview

This application is an internal tool for authorized enterprise employees that automates business workflows by integrating with Google Workspace (Gmail, Calendar, Sheets, Docs, Slides, Drive, Apps Script).

## Target Users

This application is for internal use by authorized employees only.

## Features

- 📧 **Gmail Automation**: Extract structured data from messages, send automated emails  
- 📅 **Calendar Integration**: Display events in task board, create automated reminders  
- 📊 **Spreadsheet Processing**: Execute SQL-like queries on spreadsheet data  
- 📄 **Document Processing**: Extract content from Docs for workflow automation  
- 📽️ **Presentation Processing**: Extract content from Slides for reporting  
- 💾 **Drive Integration**: Access and execute custom Google Apps Scripts  
- ⚙️ **Custom Script Execution**: Run user-created Apps Script workflows
